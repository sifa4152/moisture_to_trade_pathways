# Coupled moisture-to-trade pathways analysis

This repository contains the code and workflows used in the manuscript:

> *Coupled atmospheric moisture and trade networks reveal a concentration of global freshwater risk in a handful of countries* - Fahrländer et al. (in prep., Apr 2026)

It implements a coupled network framework linking atmospheric moisture flows and virtual water trade to quantify transboundary water dependencies.

---

## Overview

The workflow integrates two global systems:
- atmospheric moisture flow networks (Reconciled dataset from De Petrillo & Fahrländer et al. 2025)
- virtual water trade networks (CWASI database)

Countries are used as the common analytical unit to assess cross-system water dependencies.

---

## Data Sources

All input datasets are publicly available:

- Virtual water trade and water footprint data: CWASI database  
  https://zenodo.org/doi/10.5281/zenodo.2643484  
  (Tamea et al., 2021)

- Atmospheric moisture flow data (ERA5-based reconstructions):  
  https://zenodo.org/doi/10.5281/zenodo.10400694  
  (De Petrillo et al., 2025)

- Economic data (GDP): World Development Indicators  
  https://data.worldbank.org/indicator/NY.GDP.MKTP.CD  

- Country boundaries (maps): Eurostat GISCO  
  https://ec.europa.eu/eurostat/web/gisco/geodata/administrative-units/countries  

No raw datasets are modified. All processing is performed through the scripts described below.

## Repository Structure

### Data
```
data/
├── raw/
│ ├── auxiliary/ # GDP, country shapes, external auxiliary datasets
│ └── networks/ # Raw CWASI and atmospheric flow datasets
│
└── processed/
├── auxiliary/ # Harmonised supporting datasets
└── networks/ # Country-level network matrices and metadata
```

- `data/raw/` contains original datasets as downloaded from external sources  
- `data/processed/` contains harmonised, analysis-ready datasets generated by preprocessing scripts  
---

### Scripts

The workflow is organised into three stages:

#### 1. Pre-processing
Location: `scripts/1_pre_processing/`

- `preprocess_networks_v2.py`  
  Converts raw datasets into harmonised country-to-country networks and auxiliary mapping files stored in `data/processed/`.

---

#### 2. Network analysis
Location: `scripts/2_network_analysis/`

- `main.py`  
  Entry point for all network analyses.

- `analysis_functions.py`  
  Core functions for computing network metrics and cross-network dependencies.

- `settings.py`  
  Configuration file defining parameters and file paths.

This step produces network metrics and intermediate outputs used for post-processing. Flags to enable/disable parts of the analysis are included in `settings.py`. All filepaths, including input and output and analysis thresholds/parameters are set in the settings script (please adjust if needed). 

---

#### 3. Post-processing
Location: `scripts/3_post_processing/`

- `plot_all.py`  
  Main script to reproduce all figures in the manuscript.

- Individual figure scripts:
  - `fig2_chord_diagrams.py`
  - `fig3_asym_gdp_maps.py`
  - `fig4_exposure_n_mediators.py`
  - `fig5a_total_flow_loss.py`
  - `fig5b_sankey.py`

- Supporting modules:
  - `plot_functions.py`
  - `plot_settings.py`
  - `stats_analysis.py`

Outputs are written to the `output/` directory. `plot_all.py` executes all plotting functons. Alternatively, individual figure scripts can be executed separately. In both cases filepaths and plot settings have to be modified in `plot_settings.py`. 

---

### Output
```
output/version_YYYY-MM-DD/
├── figures/ # Final figures (PNG, SVG)
└── results/ # Network metrics and analysis outputs (CSV, XLSX)
```
The output folder is not included here but is generated automatically when running the code.
Each subfolder corresponds to a fully reproducible run of the pipeline. Versioning is used to track updates in analysis and figures. The version date is set in `scripts/2_network_analysis/settings.py`.


---

## Workflow

The full pipeline can be executed sequentially:

### 1. Pre-processing
```bash
python scripts/1_pre_processing/preprocess_networks_v2.py
```

### 2. Network analysis
```bash
python scripts/2_network_analysis/main.py
```

### 3. Post-processing (figures and outputs)
```bash
python scripts/3_post_processing/plot_all.py
```
